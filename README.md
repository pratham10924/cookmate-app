# CookMate AI 2.0: phone app + website + backend

A hands-free, multilingual cooking assistant. It runs three ways from one codebase:

| | What it is | How people get it |
|---|---|---|
| **Android / iOS app** | Native app (Capacitor) using the phone's own speech recogniser and voice | APK built by GitHub Actions, or Android Studio / Xcode |
| **Installable web app (PWA)** | Works offline, opens full-screen from the home screen | Open your site on a phone → "Install" / "Add to Home Screen" |
| **Website** | Same app in any browser | Your server's URL |

```
cookmate/
├── public/                  ← the app (shared by website, PWA and phone app)
│   ├── index.html
│   ├── css/app.css
│   ├── js/  config · native · data · i18n · core · voice · kitchen · lists · main
│   ├── manifest.webmanifest, sw.js, icons/   ← installable + offline
├── server/                  ← Node.js + Express + SQLite backend
│   ├── src/  server · auth · api · db
│   ├── data/src/            ← recipe source files (edit these)
│   ├── scripts/build-data.js
│   └── test/api.test.js     ← 12 API tests
├── android/  ios/           ← native projects (generated by Capacitor)
├── assets/                  ← icon + splash sources
└── .github/workflows/android.yml   ← builds the APK in the cloud
```

## 1. Run the server (website + PWA + API)

Needs **Node.js 18+**.

```bash
cd cookmate/server
npm install
cp .env.example .env          # Windows: copy .env.example .env
npm start                     # → http://localhost:3000
npm test                      # 12 tests
```

Add `ANTHROPIC_API_KEY` to `.env` to turn on:

- **AI answers** to free-form questions ("is it safe to keep this overnight?"). The assistant knows your recipe, step, allergies and diet.
- **High-quality translation** of recipes into Marathi, Gujarati, Tamil and the other 15 languages. Without a key, the free MyMemory service is used, which is weaker for Indian languages. Every translation is cached in the database, so each sentence is only translated once.

**Try it on your phone over Wi-Fi:** find your laptop's IP address (e.g. `192.168.1.20`) and open `http://192.168.1.20:3000` on the phone. Note: the microphone only works on `localhost` or **HTTPS**, so for voice on a phone you need the deployed (HTTPS) site or the native app.

## 2. Build the Android app (no Android Studio needed)

1. Put this folder in a GitHub repository and push it.
2. Open the repo's **Actions** tab → **Build Android app** runs automatically (or click **Run workflow**).
3. When it finishes (about 5 to 8 minutes), download **cookmate-android** from the run's *Artifacts*. Inside is `app-debug.apk`.
4. Copy it to your Android phone and open it. You'll need to allow "Install unknown apps" once.

**Point the app at your server:** the app works offline out of the box with all 55 recipes, using accounts saved on the phone. To sync accounts, favourites and lists, and to get AI and translation, either:

- set `window.COOKMATE_SERVER = "https://your-server.com"` in `public/js/config.js` before building, or
- in the app, go to **Profile → Server address** (or **Server address** on the sign-in screen).

### Building locally instead

Install Android Studio (with JDK 21), then:

```bash
cd cookmate
npm install
npm run app:android      # syncs the web code and opens Android Studio → press ▶ Run
# or, from the command line:
npm run app:apk          # → android/app/build/outputs/apk/debug/app-debug.apk
```

After any change in `public/`, run `npx cap sync` before rebuilding.

### Play Store release

1. Create a signing key once: `keytool -genkey -v -keystore cookmate.keystore -alias cookmate -keyalg RSA -keysize 2048 -validity 10000`
2. In GitHub → Settings → Secrets → Actions, add `ANDROID_KEYSTORE_BASE64` (the output of `base64 -w0 cookmate.keystore`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` and `ANDROID_KEY_PASSWORD`.
3. The workflow then also produces a signed `app-release.aab` for the Play Console.
4. Change `appId` in `capacitor.config.json` (and `applicationId` in `android/app/build.gradle`) from `com.cookmate.ai` to your own domain, e.g. `in.yourname.cookmate`, before the first upload. It can never change after that.
5. Check the Play Console's current **target SDK** requirement. If it's higher than 35, raise `targetSdkVersion` in `android/variables.gradle`.

## 3. iOS app

You need a Mac with Xcode: `npm install && npm run app:ios`, then in Xcode set your Team and press ▶. Microphone and speech-recognition permission texts are already in `Info.plist`.

| # | Feature | Where |

| 6 | **Marathi, Gujarati, Tamil built in**: the whole interface, assistant replies and voice commands (पुढे, આગળ, அடுத்து…). Recipe steps are translated by Claude when a key is set | Language pills / Profile |

Nutrition and allergen data are approximate, calculated from standard food tables per ingredient. Hing is flagged as gluten because most compounded hing contains wheat flour.

### Adding or editing recipes

Edit the files in `server/data/src/` (`recipes-north.js` etc.), then run `npm run build:data` from the project root. The script checks every recipe (unknown ingredients, missing Hindi, bad units) and rebuilds both the database seed and the app's offline copy. The server picks up the new version on restart. You can also add recipes on a live server with the admin API (`PUT /api/recipes/:id` with an `x-admin-key` header).

## API

| Method | Path | Auth | Purpose |
|---|---|---|---|
| GET | `/api/health` | | Status |
| POST | `/api/auth/signup`, `/api/auth/login` | | → `{token, user}` |
| GET / PATCH / DELETE | `/api/auth/me` | Bearer | Profile, languages, `prefs` (diet, allergies, wake word) |
| GET | `/api/catalog` | | Recipes, ingredients (with nutrition and allergens), units, regions |
| GET | `/api/recipes?q=&tag=&maxTime=`, `/api/recipes/:id` | | Search, or one recipe |
| POST | `/api/recipes/match` | | Best recipes for `{ingredients:[...]}` |
| PUT / DELETE | `/api/recipes/:id`, PUT `/api/ingredients/:key` | `x-admin-key` | Manage recipes |
| GET / PUT | `/api/history` | Bearer | Dashboard sync |
| GET / PUT / DELETE | `/api/favorites[/:id]` | Bearer | Favourites |
| GET / PUT | `/api/shopping` | Bearer | Shopping list |
| POST | `/api/translate` | | `{texts, from, to}`; Claude or MyMemory, cached |
| POST | `/api/assistant` | | AI answer with recipe, allergy and diet context |

## Deploying the server

Any Node host with a persistent disk works (Render, Railway, Fly.io, a VPS). Set `NODE_ENV=production`, a long random `JWT_SECRET`, and optionally `ANTHROPIC_API_KEY`. Serve it over **HTTPS**: browsers only allow the microphone on secure sites.
